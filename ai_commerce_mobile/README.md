# AI Commerce Mobile (Flutter Application)

تطبيق الهاتف المحمول **AI Commerce Assistant** المبني باستخدام **Flutter 3 (Material 3)** كواجهة عميل (Presentation / Client Layer) متصل بنواة النظام الخلفي **Laravel REST API V1**.

---

## 🏛️ المعمارية والمبادئ الهندسية (Architectural Boundary)

1. **العميل كطبقة عرض فقط (Presentation Layer Only):**
   - تطبيق Flutter لا ينفذ أي منطق مالي أو حساب أرباح محلياً.
   - كافة الحسابات المالية (إجمالي التكاليف، صافي الربح، هامش الربح، ROI) وسجلات الذكاء الاصطناعي تُحسب حتمياً داخل Laravel عبر خوارزميات **BCMath** الدقيقة.
2. **عدم اختلاق البيانات أو التعدي على مستويات الحقيقة (Data Truth Preservation):**
   - يتم وسم وعرض الأرقام بحسب تصنيفها الأصلي من الخادم:
     - `OBSERVED`: حقائق سوقية مرصودة وموثقة (أسعار العروض، أسماء البائعين).
     - `CALCULATED`: أرقام مالية محسوبة حتمياً ومثبتة.
     - `ESTIMATED`: تقديرات معيارية (مثل تكلفة الشحن التقديرية أو العمولات الافتراضية).
     - `HEURISTIC`: مؤشرات الجدوى والمخاطر الخوارزمية.
     - `AI_GENERATED`: التحليل النوعي، أسباب التوصية، وخطة العمل الصادرة عن محرك الذكاء الاصطناعي.
   - يظهر تنبيه صريح في حال كان الشحن غير موثق (`⚠️ أرباح تقديرية — الشحن غير مؤكد`).
3. **فصل إشارات البائع عن جودة المنتج (Decoupled Seller Signals):**
   - تقييم البائع ونسبة رضاه (`sellerFeedbackPercentage`) معروضة بوضوح في بطاقة البائع بالمتجر، ولا تُنسب إطلاقاً كتقييم لكتالوج المنتج نفسه.
4. **أمان البيانات وبيئة الاتصال (Zero Credentials Boundary):**
   - لا يحتوي التطبيق على أي مفاتيح سرية (OpenAI API Keys أو eBay OAuth Secrets).
   - يتم تخزين رمز المصادقة (Bearer Token) بشكل مشفر وآمن عبر `FlutterSecureStorage`.
   - جميع الاتصالات الخارجية بالأسواق تمر عبر وكيل آمن (Proxy Controller) في Laravel.

## 📱 الميزات والشاشات الأساسية (Core Features & Screens)

1. **المصادقة وإدارة الجلسات (Authentication):**
   - تسجيل الدخول (`LoginScreen`) وإنشاء الحساب (`RegisterScreen`).
   - حفظ الرمز المشفر عبر `SecureStorageService`.
   - إدارة حالات الجلسة وقطع الاتصال التلقائي عند انتهاء الصلاحية (401 Interceptor).
2. **لوحة التحكم (Dashboard Screen):**
   - ترحيب المستخدم وإحصائيات سريعة (المنتجات المسجلة، فرص الشراء، عروض المتابعة).
   - شريط البحث السريع والوصول المباشر لبحث سوق eBay.
   - قائمة المنتجات المعيارية (Canonical Products) مع نطاقات الأسعار ومؤشرات الفرص.
3. **أبحاث السوق والبحث الحي (eBay Market Research):**
   - استعلام مباشر عبر `GET /api/v1/market-research/ebay/search`.
   - عرض أسعار العروض، الشحن المجاني/المدفوع، حالة المنتج، وتقييم البائع المنفصل.
4. **تفاصيل المنتج المعياري (Canonical Product Details):**
   - عرض المواصفات، الفئة، والماركة.
   - ملخص النطاق السعري وأدنى وأعلى سعر.
   - قائمة العروض المربوطة بمتاجر السوق مع تقييم البائع المنفصل.
5. **مقارنة الأسعار (Price Comparison):**
   - حساب الفارق السعري (Spread) مع تحويل العملات التلقائي المستلم من الخادم.
   - جدول المقارنة التفصيلي بين عروض المنصات.
6. **التحليل التجاري الذكي (AI Commerce Intelligence Screen):**
   - شارة القرار المالي بلون دلالي (`BUY` أخضر زمردي، `WATCH` برتقالي، `AVOID` أحمر، `INSUFFICIENT_DATA` رمادي).
   - مقياس الثقة ومؤشرات الجدوى والمخاطر.
   - جدول التحليل المالي الحتمي مع وسوم Data Truth (`CALCULATED`, `OBSERVED`, `ESTIMATED`).
   - الأسباب الرئيسية، التحذيرات الاستراتيجية، وخطة العمل المقترحة.
   - إمكانية تجربة معطيات مالية مخصصة أو التبديل بين محرك Mock وOpenAI.
